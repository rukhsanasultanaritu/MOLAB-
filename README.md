## MOLAB – Educational Course Website Homepage

A responsive educational website homepage built using HTML, CSS, Bootstrap 5, and Font Awesome. The design focuses on a clean and modern user interface with a green accent color, responsive navigation, and an attractive hero section.

## 🚀 Features
-Responsive navigation bar with dropdown menus
-Topbar with contact information
-Hero section with heading and description
-Course search box UI
-Popular course categories
-Floating information card
-Custom Google Font (Inter)
-Responsive layout for desktop, tablet, and mobile devices
-Custom CSS styling and hover effects


## 🛠️ Technologies Used
-HTML5
-CSS3
-Bootstrap 5.3.2
-Font Awesome 6.4.2
-Google Fonts (Inter)

## 💻 How to Run
-Clone or download this repository.
-Open the project folder.
-Make sure index.html, style.css, and home.png are in the correct locations.
-Open index.html in your browser.

## 📱 Responsive Design

The homepage is designed to work across desktop, tablet, and mobile screen sizes using Bootstrap's grid system and CSS media queries.
